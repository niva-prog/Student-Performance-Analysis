# Student Performance Analysis

## 📌 Project Description

This project analyzes student academic performance using Python.

It uses student data such as:
- Attendance
- Study Hours
- Assignment Marks
- Exam Marks

The project helps identify high-performing students and students who need academic improvement.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

## 📊 Analysis Performed

- Calculate average exam marks
- Find highest and lowest exam marks
- Count passed and failed students
- Identify students who need improvement
- Visualize exam performance using a bar chart

## 📁 Project Files

- `student_data.csv` – Contains student performance data
- `analysis.py` – Python program for data analysis
- `README.md` – Project documentation

## 🎯 Objective

The main objective of this project is to understand student performance through data analysis and visualization.
